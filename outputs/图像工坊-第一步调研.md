## 1. 产品判断

定位建议：以成品预设为入口、以可叠加效果为核心、带轻量图层与排版的摄影/meme工坊。

区分三种对象：
- 效果：一个可独立开关、调整、排序的处理步骤，如 RGB 分离。
- 配方：效果的顺序、参数、混合方式和局部蒙版，如「旧电视截图」。
- 模板：配方加版式、文字、贴片与替换图片槽，如「诺基亚短信」。

不要把 100 个算法直接堆成菜单。初始界面显示风格缩略图和 3–6 个有意义的控制项，进阶参数再展开。

## 4. 图形学与 Photoshop 方法来源

- [Maxime Heckel：抖色与复古着色](https://blog.maximeheckel.com/posts/the-art-of-dithering-and-retro-shading-web/)：比较 Bayer 有序抖色、蓝噪声、色彩量化，适合解释不同纹理性格。
- [Codrops：实时抖色 Shader](https://tympanus.net/codrops/2025/06/04/building-a-real-time-dithering-shader/)：可组合处理步骤，像素尺寸、灰度开关等参数适合封装。
- [NVIDIA GPU Gems 2 第24章](https://developer.nvidia.com/gpugems/gpugems2/part-iii-high-quality-rendering/chapter-24-using-lookup-tables-accelerate-color)：LUT 用于颜色变换。颗粒、模糊、晕影等空间效果必须另做，不能塞进普通 3D LUT。
- [Maxim McNair：WebGL Image Processing](https://maximmcnair.com/webgl-image-processing)：色彩、混合模式、颗粒、双色、像素化、阈值、抖色、晕影、色差的成体系参考。
- [The Book of Shaders](https://thebookofshaders.com/)：程序图案、形状、随机、噪声等基础，适合原创纹理和动态背景；目录不代表所有章节都已完成。
- [Canvas Cycle](https://www.effectgames.com/demos/canvascycle/)：索引色循环参考，适合局部流水、霓虹等；任意照片需要先量化并选择循环范围，效果不会自动等同示范原画。
- [Adobe 滤镜参考](https://helpx.adobe.com/photoshop/using/filter-effects-reference.html)：网点、运动模糊、复印机、最小值/最大值等行为定义。
- [Envato Tuts+：Risograph](https://design.tutsplus.com/tutorials/how-to-make-a-risograph-texture-effect--cms-38557)：渐变映射、混合模式与材质叠加的配方思路；教程素材与实现思想分开处理。
- [HYTRAPE：非破坏复印机效果](https://hytrape.com/en/blogs/graphisme/effet-photocopy-workflow-non-destructif-fichier-psd-offert)：灰阶、色阶、纸/碳粉纹理和细颗粒组合，适合两种强度配方。

## 5. 建议封装的效果目录

以下为本项目建议设计，不是已经实现的功能。动态列的“可动”表示参数可随时间变化，不代表任意变化都能无缝循环。

| 类别/效果 | 成品外观或用途 | 建议主要参数 | 动态与实现注意 |
|---|---|---|---|
| CRT | 老电视、街机屏幕 | 扫描线、荧光栅格、弯曲、辉光、噪声 | 扫描/闪动可动；Pixi 与磷光栅格项目参考 |
| VHS | 模拟录像带 | 跟踪条、偏色、色度模糊、噪点 | 可动；不同于 CRT 显示屏纹理 |
| Bayer 抖色 | 有规律的点阵 | 矩阵、像素大小、阈值、色板 | 可动；Dithermark/Codrops |
| Floyd–Steinberg / Atkinson | 误差扩散点阵 | 算法、色数、对比度 | 原生有顺序依赖，别承诺廉价 GPU 并行 |
| 蓝噪声抖色 | 更均匀的非规则纹理 | 粒度、阈值、色板 | 可动；避免帧间噪声过度闪烁 |
| 像素化 | 方块化照片 | 网格大小、网格起点、采样方式 | 量化和像素化独立开关 |
| 限色/复古色板 | 掌机、8位视觉 | 色数、指定色板、保留颜色 | 可与抖色组合 |
| 索引色循环 | 局部色流动 | 循环色段、速度、方向、平滑度 | 动态核心；先生成索引再循环 |
| 色相循环 | 全画面虹彩变化 | 范围、速度、相位 | 与索引色循环分开 |
| RGB 分离 | 红蓝边缘、故障 | 距离、方向、径向/线性 | 可动；不等于冷暖色温 |
| 画面震动 | 手持/冲击 | 幅度、频率、旋转、节奏 | 动态；需边缘补偿 |
| 胶片配方 | 摄影成片 | 色彩强度、颗粒、柔光、褪色 | LUT + 空间效果；不声称真实胶片复刻 |
| 颗粒/尘点/划痕 | 胶片与档案感 | 大小、密度、强度、种子 | 可静可动，保留冻结种子 |
| Halation | 高亮边缘暖色溢出 | 阈值、半径、暖色、强度 | 与普通 Bloom 分开 |
| Bloom / 柔光 | 灯光散射、梦幻摄影 | 阈值、范围、强度 | 留住主体细节 |
| 漏光 | 边缘曝光染色 | 位置、形状、颜色、混合量 | 可缓慢变化 |
| LUT 调色 | 一键摄影色调 | 强度、曝光补偿 | 明确输入色彩空间；首版优先 sRGB 照片 |
| 渐变映射 | 双色、酸性、金属色 | 色标、亮度分布、混合量 | 不是简单叠一条渐变 |
| 分离色调 | 阴影/高光不同色 | 双颜色、平衡、饱和度 | 摄影常用 |
| 色阶/曲线/基础调整 | 成片修正 | 曝光、对比、冷暖、黑白场 | 简单面板 + 进阶曲线 |
| 电影裁边 | 宽画幅构图 | 比例、裁切焦点、边框色 | “真实裁切”和“叠黑边”两种模式 |
| 裁剪后晕影 | 当前构图的暗角 | 中心、范围、羽化、强度 | 用裁剪后坐标计算 |
| 运动/径向模糊 | 拖影、冲击、速度 | 方向、距离、中心、保护区域 | 静图方向模糊与跨帧拖尾分开 |

| Riso | 双色错版印刷 | 2–3 色、错版量、颗粒、纸色 | 整套配方 |
| 复印机 | 黑白 zine、海报 | 黑场、阈值、碳粉、边缘 | 保留适量中间调版本 |
| 印章/油墨 | 盖章、缺墨字 | 扩散、破损、纸纹、颜色 | 与最小值/最大值配合 |
| 色调分离/曝光反转 | 极化图像、实验海报 | 阶数、阈值、配色 | 可动 |

| 像素排序 | 条纹拉伸 | 方向、排序依据、阈值区间 | 计算成本需实测 |
| 电子包浆 | 转发 meme 质感 | 缩放、压缩、偏色、锐化 | 建议可控模拟，保留原图 |
| 玻璃/折射 | 棱镜、磨砂、扭曲 | 区域、折射、模糊、色散 | 区域效果，不默认覆盖整个主体 |

## 7. 图层、素材与轻量平面设计

首版建议对象：图片、文字、形状/线、贴片、调整层、组。支持移动缩放旋转、前后顺序、透明度、锁定、隐藏、复制、组合、对齐、吸附、撤销重做。

效果可以作用于单图层、图层组或整体；明确区分图层顺序与图层内效果顺序。基本混合模式可先做正常、正片叠底、滤色、叠加、柔光、差值；局部效果需要矩形/圆形/渐变蒙版及简单擦除保护。

贴片分三种：
- 程序生成：HUD、十字、星芒、标尺、网格、条纹、符号，易调色且适合动画。
- 原创/许可明确的位图：纸边、胶带、污渍、灰尘、漏光；记录作者、来源、许可及是否可再分发。
- 用户导入：PNG/SVG，保留透明背景；SVG 需经过安全处理。

取色包括吸管和整图色板提取；允许锁定喜欢的颜色再重新生成其余颜色。文字先支持字体、描边、底色、阴影、字距行距、对齐与环形/简单路径，复杂段落绕物体排版可后置。

## 8. 动态与导出建议

先做“静态照片产生 2–6 秒动态”这条明确路径；视频输入、逐帧绘画、音乐节拍同步留后续。

统一提供播放/暂停、时长、速度、幅度、随机种子与静帧导出。周期动画可以使用归一化进度；噪声、反馈和残影需要额外处理才能无缝循环。

静态优先 PNG/JPEG/WebP；动态先明确 GIF 与一种视频格式的优先级，再做浏览器/编码验证。透明动态可先考虑 PNG 序列；不能默认 GIF 的透明度适合柔光边缘，也不能假设所有视频编码支持 Alpha。

预览使用缩小画面；导出用原始尺寸重新渲染，颗粒和模糊半径要有一致的缩放规则。高分辨率要处理纹理限制；分块渲染时模糊和阴影要留边界，历史帧效果另设计。

保存工程应包含源图引用或文件、图层、蒙版、配方版本、参数、随机种子、时长与字体信息，而不只是导出扁平 PNG。

## 9. 预设封装规范建议

每个预设至少包含：ID、名称、版本、标签、适合用途、效果链、默认参数、常用控制项、进阶控制项、混合方式、蒙版规则、动态能力、循环方式、来源和授权、缩略图、性能等级。

一键恢复、前后对比、A/B 快照、四宫格比较、收藏、最近使用、保存我的配方应作为基础体验。随机化应可锁定曝光、色板、文字和主体保护，而不是把全部参数一起打乱。

## 10. 首版范围与下一步

首版建议优先：图层/文字/贴片基础、裁切和取色、24 个左右基础效果、12 套成品配方、若干动态模式、前后/四宫格对比、工程保存。数量是范围建议，不是交付承诺；需在效果评测后定稿。

第二阶段再扩展玻璃折射、像素排序、复杂残影、更多印刷质感、丰富模板、短视频导入。

下一步应先制作一份可视化效果样册，统一使用测试照片比较每个方向；经风格选择后再画界面与搭建最小原型。当前没有创建 Notion 页面、Figma 文件、Canva 设计，也没有调用 OpenArt 生成素材。

需要用户选择的关键项：摄影成片和 meme/实验视觉的优先比例；电脑优先还是手机优先；动态导出优先 GIF 还是 MP4；文字环绕指沿路径还是绕物体排版。未回复时可暂按“桌面优先、两类用途均衡、静态图片为主、短循环为辅”继续规划，但本轮不进入制作。
