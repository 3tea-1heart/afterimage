# 余像 V10.18 本地使用包

解压后双击 Start-Afterimage.cmd，在浏览器打开 http://127.0.0.1:4173/ 。需要 Node.js，保持启动窗口运行。

顶部“物件工坊”：选择卡片 / CD / 相框 / CRT，再选择对应的介质预设。可直接抓住物件拖转，松手有短暂惯性；滚轮靠近或远离；双击翻面（CD 为开合）。CD 下方“开合”把手可以左右拖动。

12 套预设会组合处理照片、版式和材质；填写标题与副标题可更新题签、专辑封面和侧脊。内容来源、照片替换、裁切、细材质参数收在“精调与内容来源”。

修改完成后点击“保存物件设置到工程”，然后在主界面“保存工程”导出 JSON。PNG 可直接导出2400×2400，放回二维编辑器的是静态图片层。未实现物件视频导出或多物件实时场景。本包是本地网页版，不是新的 EXE/APK。
