# 图像工坊：第二轮扩展调研

日期：2026-10-25。延续第一轮，仍然只做研究；没有开发、导入素材、生成效果样张或发布网站。

本轮用 Exa 做 8 组搜索，共请求 51 条结果；另直接读取重点网站。完整搜索索引另存为《图像工坊-第二轮来源索引.json》，包含初筛后未选用的结果，不能将索引条数理解成已验证可用组件数量。以下判断基于作者页面、README 和教程文本；未运行代码、未测试动画与导出，没有把作者性能宣称当成实测结果。

## 1. 本轮最重要的发现

第一轮主要覆盖屏幕、像素和基础摄影。这轮补充：印刷线条结构、绘画式图像简化、实验暗房、时间扭曲、动态字体，以及可导入的现成调色资源。

建议在产品中分出“摄影成片”“图形印刷”“动态实验”“文字版式”四个浏览入口，底层仍然共用图层和效果链。手绘类只是独立可选分类，不应成为摄影默认处理。

## 4. 代码复用的实际判断

- spite/sketch：MIT 代码，适合研究排线/雕刻。但示例的纸张纹理、模型有其他来源，代码许可不能直接覆盖这些素材；旧 README 的浏览器兼容说明也不能当作当前结论。
- drifttype、tightset：页面标注 MIT，是路径文字和自动文字布局的小型候选。两者都较新，中文、标点、组合字符和导出仍需测试。
- Hydra / hydra-synth：仓库标注 AGPL-3.0。先保留为动态效果研究对象，后续结合网站的开放方式决定是否集成，不将其当 MIT 组件。
- Variable Time：开源工具和附带字体分别看。官方说明部分字体只开放个人非商业使用，商业用途需联系字体作者。
- Space Type Generator：作者介绍为开源工具；本轮没有逐版核验主仓库许可。搜索到的单线字派生样例注明 BY-NC-SA，不能据此推定整个项目都同一许可，也不能默认可商用内置。
- Efecto、ATOM、Void：适合作为产品/效果参考，本轮没有取得可复用代码许可的充分证据。
- 论文或教程给出方法，不等于提供了可以直接嵌入的高质量浏览器实现。

## 6. 对产品设计新增的要求

1. 效果卡片标明用途：照片处理、文字效果、背景生成、需要第二张图、需要时间源。避免用户给一张静态图应用真正的时间扫描却不知道缺什么。
2. 模式分为轻量参数动画、需要历史帧的效果、编码处理三类。后两类必须有重置、预热与可复现导出策略。
3. 字体列出中文覆盖与可变轴；不对没有宽度轴的字体显示无效的宽度动画控制。
4. 材质按角色分类：颜色纹理、透明贴片、位移图、遮罩。纸纹不是万能的 Overlay 图层。
5. 调色支持导入 CUBE/HaldCLUT，标注输入条件；不要把 Log 视频 LUT 直接应用于普通 sRGB 照片并承诺正确颜色。
6. 推荐入口基于成片用途，算法名放到进阶面板。反应扩散的 feed/kill 应映射为有可用默认值的“斑点/迷宫/分裂”等模式。

## 7. 优先顺序

优先做样张验证：线雕、蓝晒、Orton、渐变映射热图、可导入 LUT、路径文字、自动标题填框。它们既有辨识度，又能直接服务摄影或 meme。

第二批：点描、Kuwahara、万花筒、空间文字、金属标题、材质位移。

独立动态实验区：狭缝扫描、反馈、Datamosh、反应扩散。先验证效果和导出，再决定是否进入默认首页。

目前的完成状态是“新增来源与可封装方向已整理”，不是“28 个效果已经制作”。
