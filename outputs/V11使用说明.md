# AFTERIMAGE V11.0 本地使用包

解压后双击 Start-Afterimage.cmd，在浏览器访问 http://127.0.0.1:4173/ ，需要 Node.js。

左侧工具：V选择、M移动、S缩放、R旋转、H平移、Z视图缩放。左侧“动态”打开多段运动预设、关键帧编辑、粒子 / 液态 / 分片效果与底部轨道。设置按钮可选择配色、查看快捷键、启用自动化接口并运行命令JSON。

物件工坊新增精装书、播放器和复古桌面。“编辑部件”可换CD盘面、书页图片；书页文字可以编辑。播放器可打开本地音频，资源仅在会话中使用。双击书籍或使用开合把手打开；桌面屏幕拖动窗口。物件设置须显式保存，再从主界面导出工程。

书籍目前只有一组对页，不含柔性翻页；时间轴是图层动画，没有完整视频剪辑或音轨；物件动态仍不导出视频。模型为程序样机。新实时贴图粒子开关已完成语法检查，尚需更多设备验证。未重建EXE/APK。

完整历史见HISTORY.md，自动化示例见afterimage-studio/API.md，来源见SOURCES-V11.md。
